# PI 데스크 포지션 평가 엔진

증권사 자기매매(PI) 데스크의 포지션을 넣으면 손익과 거래비용, 리스크 한도 사용률을 계산하고
**모든 숫자 옆에 그 숫자가 나온 산식과 대입값을 함께 보여주는** 웹 도구입니다.

**데모:** https://trading-risk-engine-chi.vercel.app 
(무료 서버라 한동안 접속이 없었다면 깨어나는 데 최대 1분 걸립니다)

![홈 화면](docs/screenshots/home-desktop-light.png)

## 왜 만들었나

평가 도구가 내놓는 숫자는 "왜 이 값인가"에 답할 수 있어야 믿을 수 있습니다.
이 도구는 예측이나 추천을 하지 않습니다. 주어진 포지션을 정해진 규칙대로 평가하고,
그 과정을 누구나 따라가며 검산할 수 있게 보여주는 데 집중했습니다.

## 할 수 있는 일

- **포지션 평가:** 주식과 선물의 평가손익, 수수료, 증권거래세, 순손익을 계산합니다.
- **근거 확인:** 계산 근거 줄을 짚으면 그 값에 쓰인 입력 칸이 함께 강조됩니다.
- **체결로 쌓는 북:** 매매 체결을 입력하면 평균단가와 실현손익이 이동평균법으로 갱신됩니다.
- **북 현황:** 전체 노출과 한도 사용률을 보고, 하루 한 번 스냅샷으로 손익 추이를 남깁니다.

![근거 추적](docs/screenshots/state-trace-highlight.png)

위 화면은 `거래세` 줄을 짚은 모습입니다. 매수 포지션의 거래세는 팔 때의 금액(평가가격)에 붙기 때문에
진입가는 강조되지 않습니다. 어떤 입력이 쓰였는지는 화면이 추측하지 않고 계산 엔진이 직접 알려줍니다.

## 숫자를 믿을 수 있는 이유

- 금액은 소수점 오차 없이 계산하고, 원 미만 처리는 시장 관행을 따릅니다.
- 세율과 계약승수는 한 곳에 모아 두고 출처와 확인한 날짜를 함께 적었습니다.
- 재평가할 때마다 두 가지 방식으로 합계를 따로 내어 서로 맞는지 확인합니다.
- 평가 이력은 고치거나 지울 수 없습니다.
- 테스트의 기대값은 문서에 적은 손계산 결과를 그대로 씁니다.

## 직접 실행하기 (Windows)

Python 3.11 이상과 Node 20.19 이상이 필요합니다.

```powershell
npm install
npm run setup   # 최초 1회: 가상환경, 의존성, 예시 데이터
npm run dev     # http://localhost:5173
```

예시 데이터의 체결가와 선물 가격은 화면을 보여주기 위한 값이며, 주식 시세만 무료 소스에서 실제 종가를 가져옵니다.
